>現在は、「earthquake-early-warning-receiver.html」こと「緊急地震速報受信機」しか機能していない事と、それも機能するか試験中ですので、実際に動作していたらIssuesへ飛び込んで報告してもらいたいと思います。
## 概要
翻訳してみたら分かる通り、「情報受信機」です。
即時に情報を受信して表示するものです。  
## API詳細
### eewr
[P2P地震情報](https://p2pquake.net)を使用しました。  
URLは[こちら](https://api.p2pquake.net/v2/history?codes=556&limit=1&offset=0)です。
## プライバシー・ポリシー
本サービスでは以下の情報を扱います。
### eewr
- 利用目的は緊急地震速報(警報)を受信して表示するものですが、creativecommons zero v1.0 universalにより改造し公開して良いものとします。
- Googleアナリティクスを使用していないため、Googleにデータが送信されることはありません。
- ユーザーはIssuesでバグ・エラーの解消依頼が出来るものとします。また、時々、動作が落ちる場合がありますが、待機または開き直したりすると解消する可能性があるため、それについてはIssuesでの報告は無視するものとします。
- 運営者は本プライバシー・ポリシーを変更できるものとします。
